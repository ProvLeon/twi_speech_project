1. Project Overview
Objective: Develop a production-ready Twi speech recognition system with ≤30% WER across major dialects
In-Scope:
* Speech data collection & validation (50+ hours)
* Core CNN-GRU model development
* Web API deployment
Out-of-Scope:
* Mobile offline functionality
* Multi-dialect support (Akuapem/Fante)
* Enterprise-grade SLA
* Advanced language model integration
Key Deliverables:
1. Curated Twi speech dataset
2. Trained CNN-GRU model (TensorFlow)
3. Web API endpoint
4. Simple Web Demo interface

4. Detailed Timeline (4 Months)
Phase 1: Data Collection & Prep (Months 1 – April)
* W1-3 (01 - 14): Recruit 50 speakers via community networks 
* W3-5 (15 - 20): Record 20hr raw audio from smartphones (24m/speaker)
Phase 2: Model Development (Months 2-3 – May/June)
* W6-9 (05 - 31): Custom CNN-Transformer(CNN-GRU) implementation
* W10-13 (02 - 28): Training & optimization
Phase 3: Deployment (Months 4 – July)
* W14-18 (01 - 31): API development and deployment on Render
